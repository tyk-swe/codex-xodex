# Changelog

## 0.1.0

Initial release. SQLite schema 1; private engine API v1.

- Task-to-PR workflow with allowlisted GitHub repositories, retained attempts,
  rootless Podman commands, PTYs and 17 MCP tools.
- Owner-required validation, protected Git publication and reconciliation of
  uncertain commands, edits and PR requests.
- Private Unix-socket services, guided owner setup and offline administration.
- Installed `setup`, `build-worker` and `smoke` commands, packaged deployment
  assets, resumable setup and configuration-relative runtime defaults.
- Source, wheel and archive tests; reproducible source packaging with checksums.

Earlier development snapshots are not supported releases. No migration layer or
automatic deletion is provided. External protocol versions are unchanged.
